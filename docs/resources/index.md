## 📖 Glossary

<html>
  <details>
    <summary><strong>UNITY TERMS</strong></summary>
<dl>
  <dt>GameObject</dt>
  <dd>Any object in a scene. On its own it does nothing; its behavior comes from the components attached to it.</dd>
  <dt>Component</dt>
  <dd>A piece of functionality attached to a GameObject, like a Sprite Renderer, a Collider2D, or one of your scripts.</dd>
  <dt>MonoBehaviour</dt>
  <dd>The base class for most scripts you attach to GameObjects. Unity calls its methods (<code>Awake</code>, <code>Start</code>, <code>Update</code>) for you.</dd>
  <dt>Scene</dt>
  <dd>A level or screen in your game, like a main menu or Level 1.</dd>
  <dt>Inspector</dt>
  <dd>The editor panel that shows the selected GameObject's components and their settings.</dd>
  <dt>Prefab</dt>
  <dd>A reusable GameObject saved as an asset, so you can create copies of it (enemies, pickups, cards) in any scene.</dd>
  <dt>Rigidbody2D</dt>
  <dd>A component that lets a GameObject be moved by Unity's 2D physics.</dd>
  <dt>Collider2D</dt>
  <dd>A component that gives a GameObject a shape for detecting collisions and triggers.</dd>
  <dt>ScriptableObject</dt>
  <dd>A data asset you edit in the Inspector. Useful for keeping game content (questions, dialogue, scenarios) out of your code.</dd>
</dl>
  </details>
</html>

<html>
  <details>
    <summary><strong>DESIGN TERMS</strong></summary>
<dl>
  <dt>Mechanics, Dynamics, Aesthetics (MDA)</dt>
  <dd>The rules of a game, the behavior that emerges when it's played, and the emotional response it creates in the player.</dd>
  <dt>Exogenous vs. endogenous</dt>
  <dd>Games where the context is a wrapper around the learning, vs. games where the context <em>is</em> the learning.</dd>
  <dt>Learning mechanic / game mechanic</dt>
  <dd>In the LM-GM model, an action drawn from learning theory vs. an action drawn from game design.</dd>
  <dt>Gameplay facilitator</dt>
  <dd>A mechanic that adds fun or challenge but isn't intertwined with the learning itself.</dd>
  <dt>Psychological reactance</dt>
  <dd>The defensive reaction people have when they sense someone is trying to change their attitudes or behavior.</dd>
</dl>
  </details>
</html>
