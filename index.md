## 💡 What This Is

This is a growing collection of tested prompts for vibe-coding educational games, along with the design thinking that should come *before* any code gets written.

Most AI-generated "educational games" end up as a quiz with points stuck on top. This library takes a different approach: <span class="highlighter">the core mechanic should *be* the skill you're teaching</span>. The prompts here help you design that way first, then build it in Unity.

{:.highlight}
This site assumes some programming experience. New to coding or Unity? The [Start Here]({% link docs/start-here.md %}) page links to free beginner resources so you can get up to speed.

## 🧭 How to Get Started

1. **Set up your tools.** Follow the checklist on [Start Here]({% link docs/start-here.md %}) to install Unity and save your context block.
2. **Start with your learning goal, not your game idea.** What should a player be able to *do* after playing? The Design for Learning section helps you turn that into a mechanic.
3. **Build one small piece at a time.** Pick a prompt, run it, test it in Unity, commit to Git, and repeat. Small prompts beat giant ones.

---

## ⚠️ A Few Ground Rules for Working with AI

<div class="warn" markdown="block">

- **You're still the designer.** AI is great at writing code and generating options, but it doesn't know your learners. Judge every suggestion against your learning goals.
- **Read the code before you trust it.** AI assistants confidently use outdated Unity features or invent methods that don't exist. If something looks off, ask the AI to explain it.
- **Protect player data.** If your game logs player actions for research or assessment, follow your program's and IRB's rules for collecting and storing data, especially with real students.

</div>
